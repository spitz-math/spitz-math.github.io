Students type the Session ID it gives you. Everyone on your roster is ready to go the moment it is made.

My tests

Make a test from released STAAR questions in the question bank, your own questions (any subject), or both. Each test is for one course: other teachers of that course can use it and make their own copy, but only you can change it. Tests stay off the students' practice list.

Spitz CheckpointMy roster

You can load and fix any teacher's roster. Teachers see only their own.

Bring in a class list

Get your students straight from Google Classroom. A small Google window opens, sends your classes here and closes itself. The first time, click Allow in it (Checkpoint can only read your class lists). Then pick which classes to add. Do it again any time to add new students.

Or upload a class list file (.csv), like a grades file downloaded from Google Classroom or any spreadsheet saved as CSV that has a column of student emails. Each student’s name and email go in the box below so you can check them before adding.

Add students

Students on your roster only type the Session ID; their name and period come from here. Paste one student per line: school email, first name or initials, class period. You can copy the three columns straight from a spreadsheet. Each email is turned into the student’s private code right away and is never saved.

Students who signed in to one of your sessions can also be added from My sessions with Add to roster.
