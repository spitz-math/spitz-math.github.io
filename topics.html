Hidden: students can't pick it. Open: students can pick it. 📌 Assigned: turns on the lock, so students can only play assigned sets. ⭐ Suggest: shows it in the hub's suggested banner. Suggested and assigned sets both earn the score bonus. Green topics are the ones students can play.

Note and bonus

% more points

A run counts when its set is suggested or assigned and every topic played is one of its suggested or assigned topics. 0 turns the bonus off.

How to get the key (one time)
  1. Open GitHub's new fine-grained token page.
  2. Name it Spitz site, set Resource owner to spitz-math, and pick an expiration (up to a year).
  3. Under Repository access, choose Only select repositories and pick spitz-math.github.io.
  4. Under Permissions, set Contents to Read and write.
  5. Click Generate token, copy it, paste it above and click Save.

It's the same key Spitz Scores uses, so if you saved it there in this browser you're already set. It stays in this browser only.
