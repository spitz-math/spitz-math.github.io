# SpitzMath design craft
1. Read `CLAUDE.md`, `docs/off-the-clock/PROJECT_BRIEF.md` and the real `arcade/index.html`, `checkpoint/dash.html`, `checkpoint/teacher/` and `teacher.css` source.
2. Derive design decisions from the current product: typography, spacing, semantic colors, motion, keyboard/focus interactions, mobile breakpoints and information density.
3. Avoid generic metric-card grids, oversized decorative hero panels and indiscriminate neon outlines.
4. Develop only inside `grad-school/`. Preserve all existing student-facing content and the root homepage.
5. Show accurate task/submission/unknown-due-date states; no fake private content in GitHub.
6. Provide desktop and 375px phone screenshots in the PR, plus an integration contract for Codex.
7. Do not merge to main; the user owns design acceptance.
